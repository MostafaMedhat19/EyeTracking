# Eye Voice Roadmap

The roadmap is organized around accessibility, privacy, reliability, and community participation. Priorities may change based on user feedback and testing.

## Now — foundation

- [ ] Publish a stable GitHub Pages demo.
- [ ] Add automated browser smoke tests.
- [ ] Create reproducible webcam-free gaze simulation for contributors.
- [ ] Document supported browsers and known limitations.
- [ ] Expand Arabic UI and speech support.

## Next — personalization

- [ ] User-editable word banks and phrase categories.
- [ ] Import/export settings and vocabulary locally.
- [ ] Additional calibration profiles for different positions and lighting.
- [ ] Caregiver-assisted configuration mode.
- [ ] Optional local-only communication history.

## Later — research and reach

- [ ] Progressive Web App and offline support.
- [ ] Additional languages and community translations.
- [ ] Accessibility studies with consenting participants.
- [ ] Performance benchmarks across low-cost devices.
- [ ] Optional privacy-preserving AI integration through a secure proxy.

## Propose an idea

Open a feature request explaining the user need, accessibility impact, privacy considerations, and how the result could be tested.
