# Security Policy

## Reporting a vulnerability

Please do not publish security or privacy vulnerabilities in a public issue.

Report them privately through GitHub's **Security → Report a vulnerability** feature when private vulnerability reporting is enabled. If that option is unavailable, contact the maintainer through the email link on [Mostafa Medhat's GitHub profile](https://github.com/MostafaMedhat19).

Include:

- The affected browser and operating system.
- Steps to reproduce the issue.
- The expected and observed behavior.
- The potential impact on camera data, transcripts, API keys, or users.
- A suggested mitigation, if known.

## Sensitive data

Never attach camera recordings, medical data, personal transcripts, or API keys to an issue. Replace sensitive values with safe test data.

## Supported version

Security fixes target the latest commit on the default branch. This project is an assistive-technology prototype and is not a certified medical device.
